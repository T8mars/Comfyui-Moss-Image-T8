# 第二批 20 轮交叉审查 · v0.1.3

日期：2026-10-16。本批与新开的独立子 Agent 已完成 20 轮逐轮往返，交换发现、复现证据和修复结果；不沿用上一批轮次。已复现的本地问题均已修复，最终源码和安装包回审通过。

## 已修复

| 问题 | 修复 |
|---|---|
| 验证脚本把空输出或缓存采样判为本轮出图成功 | 要求服务端完成、恰好一张图和明确的非缓存采样证据；Python 可用 `--allow-cached` 显式检查缓存结果 |
| 离线画布验收信任旧 proof，未绑定真实任务与图片 | 复用服务端完成/新采样检查，要求 proof、提交回执、历史中的任务 ID 一致，且图片列表完全一致 |
| 历史记录缺失时无限等待，HTTP 超时缺少任务诊断 | 增加可配置截止时间，限制单次请求；超时保存任务 ID 和队列 ID，不取消或重提任务 |
| 服务 URL 末尾带 `/` 时产生双斜杠并返回 404 | 两种验证工具统一去除末尾斜杠 |
| JPEG 内容可通过 PNG 验证，图片下载没有显式超时 | Python 校验解码后的 PNG 格式、尺寸与非恒定像素，使用显式 socket 超时并原子落盘；浏览器工具保存前检查 PNG 签名，并验证预览尺寸 |
| 复制工作目录后，启动器可能沿用旧节点 junction | 校验既有链接指向当前仓库，错误时明确退出，保留原目录供用户检查 |
| ComfyUI 子进程异常退出仍返回脚本成功码 | 启动器传递 Python 的真实退出码；真实 PowerShell + Python 验证 0 / 23 |
| 持续慢速 HTTP 响应要填满 8 MiB 才检查取消 | 网络块独立缩小为 64 KiB，文件哈希及导出仍使用 8 MiB 块 |
| Registry 安装包包含不参与运行的网络验收脚本，触发旧版扫描标记 | 通过官方 `.comfyignore` 排除开发脚本，完整源码及 ZIP 仍保留工具；等待新版本实际扫描状态 |

网络块调整降低正常持续传输下的取消延迟；不承诺任意慢速逐字节响应的绝对取消时限。Python 历史等待从提交成功后计时；画布从点击运行时计时。浏览器启动和后续图片检查不计入；队列诊断另有 5 秒请求超时。

## 验证方式

修复后的全量验证：**55 项 Python 测试、4 项 Node.js 测试通过**。以下命令在源码目录执行，需安装节点依赖、pytest 及 Node.js；PowerShell 启动器的两项测试仅在 Windows 执行。

```bash
python -m pytest -q
node --test tests/test_canvas_verification.cjs
```

Python 验证工具默认要求本次采样确实执行：

```bash
python scripts/verify_comfy.py --url http://127.0.0.1:8188/ --variant sft --size 256 --steps 4 --timeout-seconds 1800
```

仅查看缓存结果时增加 `--allow-cached`，回执中的 `verification_sampler_fresh` 会标为 `false`。画布验证通过环境变量 `MOSS_COMFY_URL` 设置地址、`MOSS_VERIFY_TIMEOUT_SECONDS` 设置历史等待时间；需要 Playwright 与 Edge。

真实 ComfyUI SFT 回归：256×256、4 步任务 `a4cb4366-ab24-4f3d-ad20-ec034fe0f3a7` 成功，工具耗时 26.6 秒；采样未命中缓存，PNG 尺寸、像素及目视内容通过。随后相同采样参数的任务 `b0018f79-c55e-4a0e-a7f4-87daf2fb4979` 被默认策略拒绝；显式缓存检查任务 `855e8d59-ff15-4bbc-a800-1c18c99d24bb` 成功并标记非新采样，图片与前次逐像素一致。后两次复用了采样缓存，没有重复执行模型。
