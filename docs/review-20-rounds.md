# 20 轮交叉审查与修复 · v0.1.2

日期：2026-10-16。主 Agent 与一个独立子 Agent 已完成 20 轮逐轮往返审查，逐项区分复现问题、验证结果和未覆盖范围。最终源码及构建包回审通过，无剩余阻断项。

## 修复

| 问题 | 修复与回归 |
|---|---|
| 同大小、保留修改时间的原子权重替换未触发缓存失效 | 文件签名和 SHA256 缓存键加入设备号、文件身份及创建/变更时间；真实 safetensors 替换测试先失败，修复后通过 |
| ComfyUI 使用 `--cpu` 时，`auto` 仍选择 CUDA | 遵循 ComfyUI 的设备设置；在真实 ComfyUI CPU 模式复核 |
| 加载前未协调已有 ComfyUI 模型显存 | 在阶段锁内调用官方内存管理接口，回收缓存后再判断可用量；受控测试覆盖指定设备及回退路径 |
| Windows 下载工具取消或任务失败时，线程池可能等待长任务结束 | 有限超时等待全部任务，共享取消事件覆盖下载、校验、复制及导出；保留原始错误和可恢复的 partial/pending 状态 |
| 非法 CFG/SLG 参数或小数步数先加载大模型再报错 | 前移合法性检查，在分配 DiT 前拒绝错误参数；有效参数计算路径不变 |

取消补丁在交叉回审时还修正了内层线程池的失败等待，以及取消异常覆盖原始错误的问题。取消不绕过文件校验；正在阻塞的 HTTP 读取仍受现有读取超时约束。
