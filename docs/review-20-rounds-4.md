# 第四批 20 轮交叉审查 · v0.1.5

本批由新开的独立子 Agent 逐轮交换复现、修复和回归证据，从 v0.1.4 重新检查，不沿用前三批轮次。20 轮已完成，本批确认的 1 项生产 BUG 已修复，无已复现未处理问题。

## 修复

两个真实进程从同一 VAE 来源直接调用导出到不同目标时，会竞争源目录中固定的 `moss-export.index.json.partial`，其中一个进程稳定报 `FileNotFoundError`。普通 CLI 仍通过根目录锁阻止同缓存的并发准备。

VAE 现在直接向流式合并函数传递内存中的 tensor 映射，不再写入源索引。原有分片索引调用、目标进程锁、配置及 tensor 原始字节复制保持兼容。已存在的旧生成索引无需删除，也不影响导出。

独立双进程回审确认两个目标均通过完整检查、SHA 相同；来源文件集合及内容不变，已有 ready 包仍有效，同目标写入仍被进程锁拒绝。探针另对源目录设置明确的 Python 写入拒绝边界，未触发任何写操作；此项不冒称 Windows ACL 验证。

新增并发回归在真实 v0.1.4 发布 ZIP 上因来源新增 `moss-export.index.json` 而失败，修复后通过；竞争导致的 `FileNotFoundError` 则由第 2 轮受控双进程独立确定性复现。空 tensor、标量、BOOL/BF16、负零及 NaN 的合法 safetensors 另经真实读写验证，未发现重排损坏。

## 验证

本批 Windows 全量 **77 项通过、3 项文件软链接测试因权限跳过**；Node.js **4 项通过**。[Linux CPU CI](https://github.com/T8mars/Comfyui-Moss-Image-T8/actions/runs/38920030202) 实跑相关子集 **28 项通过、无跳过**，包含文件软链接与新增的真实双进程 VAE 导出回归。

旧版和新版导出器另对真实小型 DiT / TE / VAE 实际导出：完整权重文件、metadata、manifest 及 tokenizer 字节一致。已有四个大模型只读取 header、manifest 和文件统计，格式及尺寸绑定正常；本批未重新导出或完整哈希 37GB，也无需更新 Hugging Face 权重。
