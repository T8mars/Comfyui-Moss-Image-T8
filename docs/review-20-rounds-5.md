# 第五批 20 轮交叉审查 · v0.1.6

本批由新开的独立子 Agent 从 v0.1.5 开始，逐轮交换复现、修复和回归证据，不沿用之前轮次。已完成 20 轮，修复两个已复现生产 BUG，当前无已复现未修复问题。

## 修复

1. **未声明的 tokenizer 输入可影响编码。** 除清单中的三个文件外，Transformers 还会读取额外模板、`added_tokens.json` 和 `special_tokens_map.json`。旧版首次检查会接受它们，额外模板目录还不会使文件指纹失效。真实官方 tokenizer 实测确认编码会改变。
   现在只接受清单对应的三个文件，在首次检查、阶段装载前后及正常返回前验证目录；文件指纹包含 tokenizer 根目录及直接子目录。额外条目会明确报错并保留，恢复导出也不能将它们标记为可用。
2. **tokenizer 临时硬链接可能写穿其他文件。** 旧版修复损坏 tokenizer 时，`copyfile` 会沿已有 `.partial` 硬链接覆盖外部文件，独立复现中把 44 字节改写为约 20 MB。
   现在复制前先移除三个已知普通临时条目；临时软链接、目录和未知条目明确拒绝并保留。无需复制的正常恢复也会清理这三个过期临时文件，不递归删除用户目录。

## 验证

五项新回归已在真实 v0.1.5 发布 ZIP 上先确认失败，修复后通过。本批 Windows 全量 **96 项通过、5 项文件软链接测试因权限跳过**；Node.js **4 项通过**。[Linux CPU CI](https://github.com/T8mars/Comfyui-Moss-Image-T8/actions/runs/38924863529) 对应核心提交实际执行相关子集，**49 项通过、无跳过**，包含这五项真实软链接验证。

四个独立权重的格式兼容检查只读取 header、manifest、尺寸及三个 tokenizer 文件；HF 远端 22 个交付文件的大小和 Git/LFS 内容 ID 一致。新服务随后完成正常加载校验，权重无需重导或重新上传。

新隔离 ComfyUI 服务以完整模型执行 Base / SFT 各一张 **256×256、4 步**，TE 显式使用 CPU；均成功完成且 sampler 新执行。服务端 PNG 与保存证据一致，尺寸、非恒定像素、内嵌参数及目视内容通过。本批未将这些小图算作新的 1024×1024、50 步验收，也未与历史不同设备选项的任务混作同参数像素比较。

普通同大小改写的 Windows stat 疑点另经 200 次真实组件试验，全部被现有校验拒绝，未作为生产 BUG 或据此改写指纹算法。
